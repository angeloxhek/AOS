# Структура исходного кода проекта

Актуально для версии коммита 108.

В данном документе описано назначение каталогов и ключевых файлов в репозитории операционной системы AOS. Это руководство поможет разработчикам ориентироваться в кодовой базе ядра, драйверов и пользовательского пространства.

## Обзор верхнего уровня

* `/configs/` - Файлы конфигурации базовой системы. При компиляции данная директория копируется в образ
* `/data/` - Основное дерево исходного кода AOS
* `/docs/` - Архитектурная и пользовательская документация по ОС
* `/scripts/` - Вспомогательные скрипты автоматизации сборки
* `/sdk/` - Системная библиотека AOSLIB и слой совместимости AOSLIB-linux
* `/userlinux/` - Портированный или адаптированный инструментарий из окружения Linux

## Подробный разбор компонентов

### 1. Ядро и Системные компоненты
Папка `/data/`. Центральная часть операционной системы. Файлы в корне этой папки формируют базовый функционал AOS:
* Архитектурно-зависимый слой HAL (`/data/arch/<arch>`) - Реализация GDT, IDT, страничного обмена (VMM), физической памяти (PMM), планировщика и обработки системных вызовов под определенную архитектуру процессора.
* Базовые сервисы ядра (`/data/\*`). Подробнее здесь -> [Ядро](kernel/README.MD) <-
* Драйверы (`/data/drivers`). Подробнее здесь -> [Драйверы](drivers/README.MD#драйверы) <-
* Обязательные драйверы (`/data/initdrivers`). Подробнее здесь -> [Начальные драйверы](drivers/README.MD#начальные-драйверы) <-
* Пользовательское окружение (`/data/userspace`). Подробнее здесь -> [Пользовательское окружение](userspace/README.MD) <-
* Заголовки ядра и VFS (`/data/include`). Подробнее здесь -> [Ядро](kernel/README.MD) <-

### 2. Средства разработки
Папка `/sdk/`. Инструменты, используемые для написания софта под AOS:
* **`/sdk/aoslib/`** - Родная системная библиотека ОС. Подробнее здесь -> [AOSLIB](https://github.com/angeloxhek/AOSLIB) <-
* **`/sdk/aoslib/agfx/`** - Встроенный в SDK независимый программный 2D-рендерер и IMGUI фреймворк. Отвечает за отрисовку интерфейса всей операционной системы. Подробнее здесь -> [AGFX](https://github.com/angeloxhek/AGFX) <-
* **`/sdk/aosliblin/`** - Слой совместимости, позволяющий компилировать код, завязанный на вызовы Linux, под нативное окружение AOS. Подробнее здесь -> [AOSLIB-linux](https://github.com/angeloxhek/AOSLIB-linux) <-

## Автоматизация сборки

* `/Makefile` - Корневой сборочный файл. Подробнее здесь -> [Файл сборки](makefile.md) <-
* `/data/arch/<arch>/arch.mk` - Сборочный файл архитектуры. Указывает, какие дополнительные флаги нужно использовать при сборке, а также как компилировать загрузчики
* `/data/initdrivers/make.mk` - Сборочный файл обязательных драйверов initrd
* `/data/drivers/make.mk` - Сборочный файл необязательных драйверов
