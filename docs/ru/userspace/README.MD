# Пользовательское пространство

Актуально для версии коммита 108.

Пользовательское пространство AOS опирается на собственный SDK, который предоставляет абстракции над системными вызовами и графическим интерфейсом.

Список стандартных программ, использующих эти библиотеки, описан здесь -> [Список пользовательских программ](../bin_folder.md) <-

## AOSLIB
Базовая системная библиотека (аналог libc для AOS). Обеспечивает:
* Обертки над системными вызовами (`syscalls.h`).
* Работу с IPC и разделяемой памятью.
* Взаимодействие с системными драйверами.
* Минимальную реализацию стандартной библиотеки Си.

## AOSLIB-linux
Слой совместимости (Compatibility Layer). Предоставляет POSIX-совместимые заголовочные файлы (`unistd.h`, `sys/stat.h`, `dirent.h`) и транслирует стандартные вызовы Linux (например, `open`, `read`, `fork`, `execve`) в нативные вызовы AOS и IPC-запросы к VFS. Используется для портирования существующих утилит.

## AGFX
Встроенный в SDK независимый программный 2D-рендерер и фреймворк Immediate Mode GUI (IMGUI).
* Работает напрямую с буфером окна (Shared Memory), полученным от Window Manager.
* Не использует системных зависимостей (Freestanding).
* Предоставляет отрисовку примитивов, альфа-блендинг, фильтры (размытие, матовое стекло) и рендеринг TrueType шрифтов.
* Содержит готовый набор UI-виджетов.
