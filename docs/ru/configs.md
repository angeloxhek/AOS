# Конфигурационные файлы

Актуально для версии коммита 108.

Конфигурация системы читается процессом `INITDRIVER` на этапе загрузки. Файлы располагаются на загрузочном диске в директории `/configs/`.

## `drivers.conf`
Определяет список аппаратных и системных драйверов, которые необходимо запустить до старта пользовательских приложений.
**Формат:** `ТИП_ДРАЙВЕРА=/путь/к/файлу.elf`
* Тип драйвера должен соответствовать перечислению `driver_type_t`.
* `INITDRIVER` запускает их последовательно и дожидается готовности каждого (перехода в статус `DRV_STAT_READY`), прежде чем запускать следующий.

## `apps.conf`
Определяет список пользовательских приложений (демонов или графических оболочек), которые запускаются при старте системы.
**Формат:** Пути к исполняемым файлам, разделенные точкой с запятой (`;`).
* Пример: `/boot/bin/desktop.elf;/boot/bin/aex.elf;`
* Приложения запускаются асинхронно.

## `authbase.ahbs`
Бинарная база данных пользователей, групп и прав доступа.
* Читается `INITDRIVER` и передается в `AUTHDRIVER` через IPC.
* Содержит криптографическую сигнатуру и версию формата.
* Если файл отсутствует или поврежден, система создает временного пользователя `localroot` с паролем `aoslocal` для аварийного доступа.
