# Список пользовательских программ

Актуально для версии коммита 108.

В директории `/boot/bin/` располагаются стандартные пользовательские приложения, формирующие графическое окружение ОС. Все они написаны с использованием `AOSLIB` и `AGFX`.

## `desktop.elf`
Оболочка рабочего стола.
* Запрашивает у Window Manager (`wnddriver`) создание фонового окна на весь экран (`WND_FLAG_BACKGROUND`).
* Отрисовывает фон рабочего стола и панель задач (Taskbar).
* Является клиентом оконного менеджера и не имеет особых привилегий.

## `aex.elf`
Графический файловый менеджер AOS Explorer.
* Демонстрирует работу с VFS через графический интерфейс.
* Использует виджеты `AGFX` для отображения содержимого директорий.
* Позволяет перемещаться по файловой системе и запускать другие ELF-файлы через системный вызов `sysspawn`.

## Утилиты Linux
Скомпилированные порты утилит из Linux (например, `tree_linux`), собранные с использованием `AOSLIB-linux`. Демонстрируют работоспособность слоя совместимости POSIX поверх микроядерной архитектуры AOS.
